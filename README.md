COME IMPORTARE IL DATASET ALL'INTERNO DEL DATABASE

1)
Andate sul sito di Postgre e scaricate l'applicazione.
Durante l'installazione è meglio se lasciate tutti i valori di default, ma se li cambiate scriveteveli da qualche parte perché servono per accedere al server all'interno del programma.
Dovrete aprire il programma chiamato Pgadmin4
  
2)
Create un database vuoto chiamato TheKnife

3)
Dopo averlo creato fate tasto destro sul database e cliccate restore

4)
Selezionate il file TheKnife.backup che vi ho dato e cliccate sul bottone restore
